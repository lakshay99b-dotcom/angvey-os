# Angvey — Agent Operating System

**LLM = Brain · Angvey = Body + Memory + Tools + Skills + Planning + Execution + Observation + Learning + Security**

This is the public-facing site and interactive demo for the Angvey Agent OS architecture.

## Vision

Angvey is not a chatbot with tools attached. It is a complete, model-agnostic Personal AI Work Agent / Agent Operating System.

- Pluggable model providers (Groq, Gemini, OpenAI-compatible, Local, Angvey-LLM, Mock)
- Full task lifecycle with persistent state
- Planner supporting sequential, conditional, loop and parallel workflows
- Universal tool registry + composable skills
- Multi-tier memory and learning from failure
- Reflection / verification engine
- Permission & safety system from Day 1
- Event/trigger system and workflow engine
- API-first design for web, mobile, desktop and developer platforms
